# dober-content-strategy

Threadsアカウント「Dober」(@dober_fullstack)向けに、保存済み全件データと最新の指標付きサンプルから導出した文体ルール・コンテンツフォーマットに基づいて投稿を作成し、`draft`としてDBにスケジュール登録する。アカウントIDは毎回 `list_accounts` で取得し、本文や正本に固定値を書かない。

## アカウント概要

- ターゲット: 自己改善・モテ・資本主義的思考に関心のある男性
- テーマ: 自己投資、規律、身体管理、お金/資本主義、恋愛/モテ、20代〜30代の危機感、生活習慣、自由な時間
- タイトル装飾: 本文の冒頭に `▫️` を付ける（つけない短文断定型もOK。下記フォーマットF参照）

## 文体ルール（厳守）

保存済み全件データと指標付きサンプルの分析に基づく必須ルール。詳細な数値と使い分けは [`references/full-corpus-insights.md`](references/full-corpus-insights.md) を参照する。

1. **命令形（〜しろ、〜せよ、〜使え、〜問え等）で終わる文を使わない。** 断定形（〜だ、〜である、〜を持っていく、等）で言い切る。
   - NG: 「語る時間があるなら、その時間を積み上げに使え。」
   - OK: 「語る時間を積み上げに変えられる人間が、最後に結果を持っていく。」
2. **「——」（em-dash, ダッシュ）を使わない。** 保存済み1,217件で使用例は0件。区切りには読点・改行・「、」を使う。
3. 箇条書きの項目は名詞止め・動詞の辞書形（〜する、〜する）でよい（命令形ではないため問題なし）。
4. 引用を使う場合、引用内の命令形もできれば地の文の断定形に言い換える。

## 方針ルール（2026-08更新）

保存済み全件データを構造分析の母集団とし、最新メトリクスが付いた投稿を成果確認のサンプルとして扱う。旧CSVだけに依存せず、直近の低パフォーマンス型は通常ローテーションから外す。

1. **アルファ/シグマ型は原則使わない。** 過去の参照実例には存在するが、指標付き高リーチサンプルでの出現が少なく直近でも伸びていないため、ユーザーから明示指定がない限り生成しない。
2. **「お金の使い方」単体の訓話は避ける。** お金テーマは「社会が思う成功/本当の成功」「金で買える/買えない」「資産・仕組み・自由」のような構造対比に変換する。
3. **最優先する見出しは危機感と現在地チェック。** 「人生が詰む」「人生を台無しにする」「ほとんどの男性ができないこと」「男たちへ送る真実」「ステータス階層」など、読者が自分を測れるタイトルを優先する。
4. **生活実感を強くする。** 身体、睡眠、AV/酒/スクロール、金、女性、親、失恋、仕事、休日など、読者の日常にある具体物を入れる。
5. **強い構造を使う。** 「A = Bとして売る」「やめる/やる」「平均/平均以上/最上位」「社会が思う/本当の」「金で買える/買えない」など、指標付きサンプルで確認できる型を優先する。

## 全件データに基づく生成ルール（2026-08更新）

保存済み1,217件の本文構造を母集団として使う。指標が付いている191件だけを成果の根拠にし、指標のない投稿の反応を推測しない。生成前に [`references/full-corpus-insights.md`](references/full-corpus-insights.md) を読み、全件の構造観察と指標付きサンプルの強い型を分けて適用する。

- 本文は通常120〜240字、8〜14行を目安にする。列挙の価値がある場合だけ上限を超える
- 冒頭は基本 `▫️`、本文は具体的な数・条件・項目を含むチェックリストまたは対比構造を優先する
- 「やめること / やること」「社会が思う / 本当の」「読者が自己採点できる基準」「生活にある具体物」を主軸候補にする
- 本文内URLは通常入れず、プロフィール・公式LINE・販売導線の役割を混ぜない
- 全件データ内の既出タイトル・項目の焼き直しを避け、生成前に直近投稿と原本の類似タイトルを確認する

## マネタイズ導線

基本方針は、Threadsで認知と信頼を取り、公式LINEへリストインさせ、LINE内でナーチャリングして商材購入につなげること。短期売上よりも、後からnote、有料記事、アフィリエイト記事、商材を追加するたびにセールスできるリスト資産を増やすことを優先する。

通常運用の主導線:

1. Threadsで危機感・現在地チェック・自己改善の必要性を喚起する。
2. プロフィールや自然なCTAから公式LINEへ誘導する。
3. LINEで教育・信頼形成・具体提案を行い、商材購入へつなげる。

早くマネタイズしたい場合の短期導線:

1. Threadsからnoteへ遷移させ、そこで有料noteを購入させる。
2. Threadsからnoteへ遷移させ、そこでアフィリエイト商材を購入させる。
3. Threads本投稿で興味を作り、返信スレッドにアフィリエイト商材リンクをぶら下げて購入させる。

投稿作成時は、すべての投稿を売り込みにしない。通常投稿はリストインに寄せ、note・有料記事・アフィリエイト記事・商材の追加時だけ、販売導線用の投稿群を作る。

## 高パフォーマンスなコンテンツフォーマット

A〜Gの7フォーマット定義は `references/formats.md` を参照する（`dober-strategy-review` と共有）。新規投稿作成時は現行の優先フォーマットに従う。

## 実行手順

### Step 1: 投稿対象期間とスケジュールを確認する

ユーザーの発話から対象期間（例: 来週）を判断する。デフォルトのスケジュールは1日3件、JST 7:30 / 12:00 / 20:00。

JST → UTC変換（`scheduled_date`に使用）:
- 7:30 JST = 前日 22:30 UTC
- 12:00 JST = 同日 03:00 UTC
- 20:00 JST = 同日 11:00 UTC

### Step 2: 投稿内容を作成する

まず、`list_accounts` でDoberのThreadsアカウントを特定し、現在アクティブな参照実例セットをDBから読み込む。`mcp__supabase__execute_sql`（project_id: `fdmhkjiqsrzktfmbqlxg`）で実行:

```sql
SELECT version, examples
FROM account_content_strategy
WHERE account_id = '<list_accountsで取得したDoberのaccount_id>' AND is_active = true;
```

取得した `examples`（A〜Gに分類された高パフォーマンス実例）を文体・構成のリファレンスとする。これらは `dober-strategy-review` により毎週更新される。

- 対象期間の投稿数を `references/formats.md` の現行フォーマット配分に従って分配する。均等配分ではなく、A〜Eを厚めにする。
- `references/full-corpus-insights.md` の全件データ観察を使い、文字数・改行・具体物・既出タイトルの重複を確認する。指標付き191件の実績構造は、模倣ではなく題材と構造の候補として使う。
- DB実例に古いフォーマット（例: アルファ/シグマ）が残っていても、上記の方針ルールを優先する。
- 通常投稿は公式LINEへのリストインを基本導線にする。短期収益化が明示された場合のみ、note、有料note、アフィリエイト記事、返信スレッドの直リンクを使った販売導線を組み込む。
- note・有料記事・アフィリエイト記事・商材が追加された場合は、その内容に合わせて「問題提起 → 必要性 → 遷移/購入」の販売投稿を作る。ただし露骨な売り込みだけにせず、通常投稿の文体と危機感・現在地チェックの型に寄せる。
- 直近で使用したフォーマット・テーマと重複しないよう、`mcp__nexauto__list_posts`で直近の投稿を確認してから作成する。
- 各投稿は上記「文体ルール」に従う。

### Step 3: draftとして登録する

`mcp__nexauto__create_post`で、`list_accounts`で取得したDoberの`account_id`、`status: 'draft'`, `source: 'ai'`として各投稿を登録する。

### Step 4: ユーザーに一覧を提示する

作成した投稿の日時・タイトル（先頭行）を一覧で提示し、内容の確認・修正依頼を受け付ける。
